# 模拟历史记忆补充实验 v1

这是独立的模拟历史实验，不是已确认真实历史事件基准。六条历史示例为明确标注的虚构数据，检索使用固定词频向量而非学习式 embedding。当前观测仍来自真实采集的本地模拟器快照，模型为真实 DeepSeek API 调用。

27 个实例的结果：故障 Top-1/Top-3 均为 2/18（11.1%），控制组 0/9，合法报告 5/27，流程失败 22/27。全部失败保留在分母。没有证实记忆收益。相较此前图模式的 4/18，本次观测更低；由于这是看到基线结果后构造的探索补充实验，不能据此推断真实历史检索的因果效果。

实际发起 44 次 provider 请求，记录输入 161,089 token、输出 15,691 token。固定代码费率的预算估计为 USD 0.0671559，实际账单未知。分布、Wilson 区间、缺失值见 [评分文件](run-001/score.json)。模型耗时为真实计时，Evidence/Gate 时间冻结到观测窗口。

每个实例保存模拟来源标记、最多三条已选择参考及其哈希；所有评测事件 ID 都被排除。参考不能作为当前 Evidence 引用，模型不获得当前样本标签。原始 [240 个测量文件及哈希](run-001/file-hashes.json)保存了报告、调用、Evidence/Artifact 和来源。真实历史模式继续保持未测，评分 comparison_complete=false。

本实验没有审批、恢复执行、人工收益或线上可靠性结论。
