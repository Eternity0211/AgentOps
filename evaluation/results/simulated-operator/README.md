# 模拟复核：真实模型输出归档

本报告遵循只读模拟操作员协议，不代表人工评价。原始文件见 `v1/run-001/`。

覆盖真实单次/图式模型运行 54 次及独立模拟历史模式 27 次，共 81 次。只有 8 次保留了可绑定到模型输出的结构化报告；73 次报告缺失，包括工作流失败与早期版本未保存报告 DTO，均未补造。8 份可用报告中共 22 条声明引用，22 条可解析；这仅说明引用完整性，不证明根因正确。

归档包括逐次结果、汇总、精确复核源码及 SHA-256 文件清单。源码版本为 `2e8b7560087925a412f7fc78152fa5899d695c62`。后端计时仅适用于本机文件读取与计算，不可推断人工速度。真实已关闭历史事件对照仍未测；模拟历史运行始终单独统计。
