# Final durability comparison v2 protocol

This plan freezes eight paired interruption cases before measurement. Each treatment is compared
with the same uninterrupted persisted-workflow fixture, and every published row must contain both
arm values and a delta. The fixed census retains failures and prohibits selective reruns.

The model and read tools are controlled typed substitutes so call, token, Evidence and replay
counters can be observed exactly. This is a durability experiment, not a real-provider diagnosis
quality result, a human-approval result, or a production reliability claim. Rate-card cost is an
upper bound rather than actual billing.

The measurement is accepted only if all eight pairs finish, terminal routes match the frozen
expectation, and duplicate external effects, ambiguous-result redispatches and lost Evidence on
resumable routes are all zero. Latency overhead must be published even when every safety gate
passes.
