# Simulated history experiment v1

Six explicitly fictional historical examples; their fixture timestamps are not claims about
real closed Incidents. No human approval or recovery is asserted. They contain general known
fault patterns, not evaluation instance IDs or evaluator label mappings.

Retrieval uses a deterministic normalized count vector over eight public terms, cosine order,
ID tie-break and at most three results. This is a simulated retrieval mechanism, not a learned
embedding or PostgreSQL confirmed-history benchmark. The source passes through existing RBAC
and historical-context validation. Each model context preserves SIMULATED_FIXTURE origin.

Run the distinct controlled-graph-simulated-memory mode on the fixed 27 snapshots with the
same provider/settings/budgets as the earlier graph. Store selected contexts and hashes. The
bank is frozen before these calls, but was constructed after single/graph results were seen;
this is an exploratory supplemental experiment, not an untouched held-out memory comparison.
Real confirmed-history remains unmeasured. Do not promote these fixtures into runtime memory.
