# 真实模型固定快照对照 v1：阶段报告

本轮没有证实诊断质量或人工效率提升。已完成单 Agent 和受控图两个模式各 27 个样本；真实历史记忆模式未测，因此不是完整三模式评测。

受控图 Top-1 比单 Agent 低 5.6 个百分点。本轮成功样本集合不同，不能把两组中位耗时之差解释为提效。Wilson 区间、全部逐项耗时和失败耗时见 [评分结果](run-001/score.json)。小样本和重复本地场景不支持生产可靠性结论。

模型实际发起 74 次请求，74 次均记录了 provider token 用量：输入 201,871、输出 24,965。这些数量来自原始调用日志，包含中断样本。逐结果账本中有一个中断结果的用量标为未知，未擅自补写。按固定代码费率算出的预算估计为 USD 0.0905193；实际账单未返回，不能当作实付费用。

失败观察包括 19 个 ToolGatewayError、18 个并行任务 ExceptionGroup、1 个模型结构化输出失败，以及 1 个结果格式缺项造成的中断。底层原因未完整记录的异常组不进一步猜测分类。不能把所有失败都归因于模型。原始快照本身保留了 46/420 个不可用 trace 读取组合。

运行在 27 个固定输入上：18 个本地真实故障观测、3 个正常观测、6 个明确派生控制。API 为真实 DeepSeek 调用；回放读取已冻结观测，不是当前线上故障。单 Agent 独立执行一次规划／读工具／诊断；图模式可进行一次有限重规划。工具目录、模型设置、初始快照和总预算相同。Gate PASS 仅代表证据准入，不等于根因正确。

本轮在提交 `4cd1061` 开始，27 个结果保存后因结果 DTO 漏列 NEEDS_MORE_EVIDENCE 中断；提交 `3479e4f` 修正后续跑。中断目录对应结果按既定规则记 FAILED，没有重发其模型请求。修正后还保存脱敏结构化报告；修正前已完成报告的完整 DTO 未留存，不能补造。每个实例的 runtime.json 记录执行时版本和源文件哈希；本轮是透明披露中断和版本变化的阶段实测，不宣称单一干净版本全路径验证。

第一个 http-500 输入曾用于提示开发 smoke，不能称为未见过的留出样本。其余案例也只覆盖已知故障家族。模拟历史库是在观察本轮结果后构造，后续结果将单独作为探索实验报告，不能冒充真实历史或未接触的记忆基准。

未发生修复建议、人工审批或产品恢复执行。评测器清理不计恢复；本轮不能给出恢复成功率、危险操作阻断率、人工节省时间、实际 MTTR 或复发率。相关确定性集成／安全测试与本轮质量指标分开。
