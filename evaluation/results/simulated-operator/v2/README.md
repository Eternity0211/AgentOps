# 待审批快照模拟复核

从已归档的真实注册工作流 v2 读取唯一一条待审批记录。按快照创建时间核验有效期，并重算提案、策略和快照指纹。1/1 绑定通过。回滚证据角色核验 0/1 通过，引入故障的部署引用实际指向 LOG，模拟建议为 REJECT。

该样本是已知负例，评估范围为绑定、证据归属和类型。实际审批决定、执行均为零。真人耗时和收益未测。81 次诊断复核采用独立分母。

复现入口为 `python -m pytest tests/unit/test_pending_archive_review.py --no-cov`。测试核对原始 SQL 字节哈希与复核输出，并覆盖篡改指纹、租户和过期时间。
